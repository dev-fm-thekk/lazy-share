A file transfer that needs its space

LazyShare moves files between nearby phones over Wi-Fi — except it pauses the second your phones get close, and only picks back up once you've backed away. It's the only app that works better the more you ignore it.

Download APK android · v1.0.0 · 250 MB

How to get a file across

It's simple. It's just backwards.

1

Start the transfer

Pick a file and a nearby device. The progress bar starts moving like any normal app.

2

Walk toward your friend

Get within arm's reach and the transfer stops cold. LazyShare does not do well up close.

3

Take a step back

Put some distance between you and it resumes right where it left off. Healthy boundaries, respected.
